## Короткий опис архітектури проєкту

### Загальний огляд

Даний репозиторій є **вебзастосунком на Django**, інтегрованим із компонентами **TensorFlow / машинного навчання**:

- **Django-бекенд** (`djangotutorial/mysite`) відповідає за обробку HTTP-запитів, маршрутизацію, бізнес-логіку, автентифікацію користувачів, роботу з шаблонами та надає вебінтерфейс застосунку.
- **Додаток Polls** (`djangotutorial/polls/`) містить логіку, інтерфейс та розділ адміністратора додатку опитувань.
- **Додатки на TensorFlow** (`djangotutorial/..._app/`) інкапсулює логіку машинного навчання, зокрема навчання моделей, оцінювання, попередню обробку даних та виведення результатів додатку.
- **Команди Tutorial** (`tutorial/`) містять команди для запуску Частини 1 завдання - Tutorial.
- **Команди Tensorflow** (`tensorflow/`) містять команди для запуску Частини 2 завдання - Tensorflow.

### 🚀 Принцип роботи (типовий сценарій)

1. **Користувач** взаємодіє з вебінтерфейсом або API Django.
2. **Django** обробляє запит через систему маршрутів (`urls.py`) та відповідні представлення (`views.py`).
3. **Інтеграція ML:**
   - Django викликає функції або скрипти TensorFlow для виконання обчислень або інференсу моделі.
   - TensorFlow обробляє дані, застосовує модель та повертає результат.
4. **Результат** передається назад у Django та повертається користувачеві у вигляді HTML-сторінки.

### 🔗 Концептуальна схема взаємодії

**Запит користувача → Django View → TensorFlow (ML-модель) → Результат → Django Response**
