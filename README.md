### Зміст звіту.

Проект на гітхаб з відповідними комітами для першої і другой частини. Опис на гітхабі функціоналу і зміст компонентів проекту. Можна з використанням UML. В опису вказати також який АІ був використаний для генерації коду. Або який проект був взятий за основу.
